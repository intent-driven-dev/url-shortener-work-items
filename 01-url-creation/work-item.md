# URL Creation

## User Story

As a visitor, I want to create a short URL from a destination URL so that I can share a simpler link.

## Acceptance Criteria

- **Given** a visitor is on the URL creation form, **when** they view the page, **then** they can see a destination URL field and a **Shorten URL** button.
- **Given** a visitor has entered a valid destination URL, **when** they choose **Shorten URL**, **then** a short URL is generated.
- **Given** a short URL has been generated, **when** URL creation completes, **then** the visitor can see the generated short URL in a result area.
- **Given** the generated short URL is displayed, **when** the visitor selects it, **then** they can follow the short URL.
